## Open Grades

Go to **Settings → Grades**. Use this page for the shared grade catalog, rather than changing an individual student's placement.

## Add or edit a grade

1. Search for the grade first.
2. Open the new-record form or edit the existing entry.
3. Enter **Grade** and **Grade Short Name**. Both must be unique.
4. Set **Grade Order** to control how the grade is listed.
5. Add an optional description, select the status, and save.

## Keep short names consistent

Use the school's established abbreviations. Student Enrollment displays Nursery classes as **N-A**, **N-B**, or **N-C**, and Kindergarten classes as **K1-A**, **K2-A**, or **K3-A**. Numeric grades combine with their class letters, such as **12A**.

The grade and class remain separate settings and placement fields. Editing a grade label does not promote students or move them to a different class.

## Verify the change

Check the grade list and its ordering. If the grade is unavailable in an enrollment selector, check its active status and the selected academic context. Review existing placements before retiring or changing a grade used in historical records.

## Before you start

Open **G12 National Exams → Excel Imports / History**. Previewing and confirming an import requires import permission. Use **Scoring** for scoring CSV imports; this page is for the G12 Excel-record workflow.

## Prepare the source

Download the available template and keep its expected structure. Preserve an unchanged copy of the source workbook. Check student IDs, academic years, campus names, center names, examination language, and selected class values.

Do not assume that a workbook from another system uses the same column names or meanings. Inspect the preview before allowing it to update records.

## Upload and preview

1. Choose the workbook using the import controls.
2. Run the available preview action.
3. Review each row's Student, Year, Campus, Exam Center, Action, and Issues.
4. Resolve any required campus or center mappings.
5. Use **Refresh Preview** after changing mappings and inspect the proposed changes again.

Check whether each row is creating a record, updating an existing record, or being rejected. Similar names are not enough to identify the correct student.

## Confirm the import

Choose **Confirm Import** only after the preview is correct. Review the confirmation outcome and import history, then spot-check affected students in Student Exam Records and Result.

If records changed since the preview or a validation message appears, review it before retrying. Do not repeatedly confirm a stale preview or change IDs to force an uncertain match.

## Protect issued documents

Treat certificate numbers and collection history as existing official data. A general student-data import is not authorization to replace issued certificate numbers or signed collection evidence.

## Before you start

Open **Students → Student Documents**. Viewing the page, uploading, previewing, downloading, and deleting documents require separate permissions.

## Find the student

Use the available year, campus, grade, and search controls. Verify Student ID, name, and relevant enrollment details before opening their document list.

## Upload a document

1. Open **Upload Student Document** for the correct student.
2. Choose **Document Type**.
3. Enter Title, Document Number, and Description as appropriate.
4. Choose the file in one of the formats accepted by the form, such as PDF, JPG, PNG, DOC, or DOCX.
5. Review the student, type, and selected file, then save.

Use the configured document type rather than placing every attachment under an unrelated category. An administrator maintains Document Types separately.

## Preview or download

Use the document's permitted preview or download action. A preview may depend on the file format and browser; download is a separate permission.

Verify that the file opens and matches its title and number before sharing it with the intended recipient.

## Remove a file

Check the target student and document before using Delete. Removing a document is not the same as withdrawing or deleting a student. Read any confirmation message and retain required school records according to the school's process.

## Troubleshooting

- **Upload fails:** check required fields, accepted file type, size limits, and the validation message.
- **Document type missing:** ask the administrator to review Document Types configuration.
- **Preview/download missing:** check the corresponding permission.
- **Wrong student:** review and correct the document association through an authorized process rather than uploading more unrelated copies.

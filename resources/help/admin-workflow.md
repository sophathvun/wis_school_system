## Before you start

Open the **Administrator** main menu. Your account determines which tools are available. Users, Roles, and Dashboard Templates currently require a super administrator account; other tools follow their own access rules.

## Choose the correct tool

| Tool | Purpose |
| --- | --- |
| Users | Create and maintain login accounts, role assignment, and campus scope |
| Roles & Permissions | Review permission definitions and configure department, role, or user grants |
| Roles | Create and maintain reusable role definitions |
| Dashboard Templates | Design and assign dashboard layouts |
| Branding | Manage system logos and other supported branding assets |
| Database Backups | Create, download, and manage database backup files |

## Recommended setup order

1. Review the departments, roles, and campuses the account should use.
2. Configure department and role permissions in Roles & Permissions.
3. Create or update the user and choose the correct role and campus scope.
4. Add user-specific permissions only when an exception is required.
5. Verify the user's intended workflow using an authorized account review.
6. Assign the appropriate dashboard and maintain routine backups.

## Understand access layers

Permission trees have main menus, submenus, and actions. Turn on the relevant main menu before its submenu and actions. Some modules also have tab permissions, record-level restrictions, or assigned-teacher rules.

Campus scope matters as well as permission. A user may have permission to edit a module but only for assigned campuses. Report access may follow different rules from editing access.

## Troubleshoot a missing menu or action

Check the account status, role status, department grants, role grants, user-specific grants, campus assignment, and required parent permissions. A visible dashboard link or an ON switch alone is not proof that every record is accessible.

After saving an access change, refresh the relevant page and verify the exact task. Avoid changing several unrelated permission sources just to make one missing action appear.

## Before you start

Open **Attendance → Subject Attendance**. Taking attendance requires the **Add / edit assigned subject attendance** permission and access to the relevant assignment.

Subject sessions come from published teaching schedules. Creating or revising teaching schedules is a separate workflow; the attendance page does not create a timetable for you.

## Open a session

1. Select the academic year and campus.
2. Select **Attendance Date**.
3. Use **My Subject Sessions** and the available session list.
4. Open the correct class, subject, teacher, and scheduled session.
5. Check the student roster before marking.

If a session is missing, check the date, teacher assignment, schedule publication, and campus access. A dated schedule revision should be used when an existing published session changes.

## Mark the students

Choose an offered status for each student: Present, Absent, Late, Excused, or Sick. Add late minutes and a note where appropriate.

**Mark Unmarked Present** applies Present to unmarked students. Unmarked students are not automatically counted as present, so review this action before submitting.

## Save or submit

- **Save Draft:** save work that still needs review.
- **Submit Attendance:** complete the session and lock it against ordinary editing.

Mark every student before submitting. Changes are not saved automatically in Subject Attendance. Check the save or submit message before leaving the page.

## Correct a submitted session

A submitted session must be reopened by someone with reopen permission. Use **Reopen for Correction**, supply the requested reason, correct the marks, and submit again after review.

If the session changed in another window, refresh and reopen it rather than repeatedly saving an old version. Use Attendance History to review recorded actions.

## Open Classes

Go to **Settings → Classes** to maintain class names and their order. A class is separate from the student's grade, academic year, campus, and study session.

## Maintain a class

1. Search the list for the required class.
2. Open the new-record form or edit the existing class.
3. Enter **Class Name**, using the established naming convention, such as **A**, **B**, or **C**.
4. Enter **Class Order** if required.
5. Choose the status and save.

Class names must be unique. Reuse a configured class letter where appropriate instead of creating a new copy for every academic year.

## Understand placement labels

Enrollment combines a grade and class for display: Nursery with class A becomes **N-A**, Kindergarten 1 with class B becomes **K1-B**, and Grade 12 with class A becomes **12A**. These labels do not mean a separate class setting must be created for every combination.

## Check the result

Verify the class appears in the list and in the intended enrollment context. Changing a class name does not transfer students. Use the student placement workflows when the student's actual class assignment must change.

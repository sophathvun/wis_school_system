## Before you start

Open **Administrator → Branding** with branding access. Branding changes are shared presentation settings, so prepare the intended assets before saving.

## Choose the correct asset

| Field | Used for |
| --- | --- |
| Dark Sidebar Logo | Navigation on the dark sidebar |
| White Sidebar Logo | Navigation on the light sidebar |
| Login Logo | Sign-in screen branding |
| Mobile Shortcut Icon | Installed or saved mobile shortcut branding |
| Favicon | Browser tab icon |
| Footer Logo | Footer branding |
| School Logo 1 / School Logo 2 | Supported school/report branding placements |

## Upload and save

1. Choose or drag the intended file into the matching upload area.
2. Check **Preview Photo** and the field label.
3. Review any footer text or other branding fields you are changing.
4. Save using the page's save action.
5. Reopen the relevant screen and verify the result.

Use the file types and size limits accepted by the form. A favicon and a large sidebar logo serve different purposes; review their legibility at the actual displayed size.

## Check both sidebar styles

Verify the dark and white sidebar variants so the logo remains readable. Check login, browser icon, mobile shortcut, and report uses separately where applicable.

Branding assets and the user's selected theme color are separate presentation choices. Replacing a logo is not the same as changing the whole application's theme.

## Troubleshooting

If an old icon still appears, refresh the page and check browser or installed-shortcut caching. If the upload fails, review the file format, size, and validation message before selecting it again.

## Before you start

Open **G9 National Exams → G9 Setting**. You may have read-only access; changing values requires permission to manage settings.

## Choose the settings scope

1. Select the academic year.
2. Choose **Academic-year defaults** or a specific **Exam Center**.
3. Confirm the scope before entering values.

An exam center's explicitly configured dates take priority over the academic-year defaults. Do not assume that changing the defaults will replace a saved center-specific date.

## Configure an exam center

In **Exam Center**, review **City / Province**, the department details, **Signer Title**, and **Signer Name** where available. Save changes using the screen's save action.

City / Province affects report headings and the signature title used by DoEYS-style reports. Use the correct location, such as **រាជធានីភ្នំពេញ** or **ខេត្តព្រះសីហនុ**.

## Set document dates

Open **Document Dates** and choose the relevant date section. Review the calendar date and its Khmer solar and lunar text before saving.

| Setting | Used for |
| --- | --- |
| Candidate List Issue Date | Candidate-list documents |
| Result Issue Date | Result-list center signature, DoEYS-style school signature, and the WIS academic office date |
| DoEYS Result Issue Date | The approval block in the individual result list |
| Student Card Issue Date | Student card documents |
| Certificate Issue Date | Certificate-related dates |

The WIS **ការិយាល័យសិក្សា** card formats the Result Issue Date as **August 12, 2026**. Its date comes from settings; it is not the current printing date.

## Check a date in the report

After saving, reopen the report for the same year and exam center. If the date is unexpected, check for a center override. If the WIS card shows a dotted placeholder, check that a calendar date has been saved in Result Issue Date.

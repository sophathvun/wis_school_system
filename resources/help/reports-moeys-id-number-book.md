## Build a customized student list

1. Open **Reports > Academic Reports > Customize Stu. List**.
2. Select an academic year, then campus and other available filters.
3. Choose the information columns needed for the task from the column groups.
4. Select a sort column and ascending or descending order.
5. Apply the filters and review headings, row order, and student IDs.
6. Use Print, Excel, or PDF.

## Choose useful columns

Include Student ID to distinguish students with similar names. Add only the identity, enrollment, or family columns needed for the report. An academic year is required to load records.

Column selection and sorting change the report output; they do not update student records or assign a new student ID.

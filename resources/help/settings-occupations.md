## Open Occupations

Go to **Settings → Occupations**. The list provides consistent occupation choices for family-member records.

## Maintain an occupation

1. Search for the existing occupation.
2. Open the new-record form or edit the matching entry.
3. Enter **Occupation Name in English** and the Khmer name when available.
4. Choose the status and save.

The English occupation name must be unique. Use a clear shared label rather than adding a new occupation for every spelling variation.

## Verify the choice

Check the saved entry and its availability in Family Management. If the occupation is missing, review its status before creating another entry.

An occupation already assigned to a family member cannot be deleted. Deactivate it instead when it should no longer be offered for new selections. Changing an occupation label updates the shared description; it does not change a parent's other family information.

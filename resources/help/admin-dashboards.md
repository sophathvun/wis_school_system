## Before you start

Open **Administrator → Dashboard Templates** with a super administrator account. A dashboard template controls presentation and assignment; it does not grant module access.

## Create a template

1. Choose **New Template**.
2. Enter the identifying details offered by the form.
3. Review status, display order, and any available scope options.
4. Create sections in the layout builder.
5. Choose the column arrangement for each section.
6. Search the widget palette and drag the intended widgets into the sections.

Multiple widgets can create rows within a column. Keep related information together and avoid a layout that is difficult to scan on smaller screens.

## Assign the dashboard

Review the form's assignment sections and select the intended users, roles, or other available assignment targets. Check all selections before saving a shared template.

Assigning a dashboard does not give its recipients permission to open restricted modules or see records outside their access scope.

## Edit and verify

Open the existing template, review its assignments and layout, make the intended change, and save. Verify the dashboard with the appropriate assigned account and check both desktop and mobile presentation.

## Remove a template

Review its assignments before using the delete action. Removing a template is different from removing a role or account; check the resulting dashboard experience for affected users.

## Troubleshooting

If a user sees an unexpected dashboard, check template assignments, status, ordering, and their role. If a widget cannot open its target feature, review the user's underlying permissions rather than adding unrelated widgets.

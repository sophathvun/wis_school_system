## Before you start

Open **Administrator → Roles** with a super administrator account. This page manages role definitions; **Roles & Permissions → Permissions by Role** manages their permission grants.

## Create a role

1. Open the available new-role form.
2. Enter Role Name and a unique Code.
3. Add a description explaining who should use it.
4. Choose the department if applicable.
5. Review global scope and Active/Inactive status.
6. Save and verify the role in the list.

Role codes accept letters, numbers, dashes, and underscores. Keep them stable and descriptive rather than using a person's name as a code.

## Assign permissions

Open Roles & Permissions and choose **Permissions by Role**. Select the role, review Role Department, enable the intended main menus, submenus, and actions, then choose **Save Role Permissions**.

Creating a role definition does not automatically give it every module permission. Review its grants before assigning it to users.

## Assign the role to a user

Use the Users screen to select the intended role and campus scope. Review the role's effects on existing users before making shared permission changes.

## Edit or remove a role

Review name, code, department, scope, and status before saving. Check assigned users before deactivating or deleting a role. The **Super Administrator** role is protected from deletion.

## Common problems

- **Role exists but a menu is missing:** check the role's permission tree and required parents.
- **Unexpected campus access:** check both role scope and user campus assignment.
- **Only one user needs an extra action:** review whether a user-specific grant is more appropriate than changing the shared role.

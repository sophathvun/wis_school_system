## Open Academic Tracks

Go to **Settings → Academic Tracks**. Tracks describe the student's academic stream and language, especially for Grade 12 placements and reporting.

## Add or edit a track

1. Find the existing stream and language combination.
2. Open the new-record or edit form.
3. Select a grade when the track is restricted to that grade.
4. Enter the English name, optional Khmer name, and a unique code when used.
5. Choose **Science** or **Social Science** as the stream.
6. Choose **Khmer** or **English** as the language.
7. Select the status and save.

Typical combinations are Science - Khmer, Science - English, Social Science - Khmer, and Social Science - English. Use the configured code or record ID when a student-import template requests the academic track.

## Verify student assignments

Check the academic track on the student's enrollment for the correct academic year. Creating a track does not assign it to students automatically.

A track already assigned to students cannot be deleted; deactivate it when retiring the choice. Avoid changing the meaning of a track already used by historical enrollments.

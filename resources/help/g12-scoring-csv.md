## Before you start

Open **G12 National Exams → Scoring**. CSV export and CSV import are separate permissions. Use the scoring CSV actions, not the general MoEYS Excel-record import, when updating grades.

## Export the scoring list

1. Select the academic year and relevant filters.
2. Use the available **Export CSV** action.
3. Keep an unchanged copy of the exported file.
4. Edit only the intended grade and Score / Rank fields using the expected column structure.

Preserve candidate identifiers and examination context. Enter A–F in grade fields. Do not move one student's grades onto another student's row.

## Preview an import

Choose the scoring CSV import action and upload the prepared file. Review each preview row's student, Score / Rank, Letter Grade, and Issues.

Check blanks as carefully as entered grades. Do not assume an empty value means the old value will be retained; inspect the proposed update before confirming.

## Confirm and verify

Correct invalid or mismatched rows first. Choose **Confirm Import** only when the preview identifies the correct students and values. Then reopen Scoring or Result and verify affected candidates.

If the source record changed since the preview, refresh or prepare a new preview and review it again. Do not bypass a conflict by changing identifiers in the workbook.

## Common problems

- **Missing import/export action:** check the matching CSV permission.
- **Unexpected subjects:** check language and selected class.
- **Grade rejected:** use A–F and review the preview's validation message.

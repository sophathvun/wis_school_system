## Before you start

Open **Attendance → Attendance Reports → Stu. Attendance Detail**. The student-detail tab and Print, Excel, and PDF actions have separate permissions.

## Choose a student and range

1. Select Academic Year.
2. Narrow by Campus and Grade.
3. Select **Student Name**.
4. Choose **Date Range** using the available calendar.
5. Review the Student Information panel to confirm the selected identity.

The date-range control displays dates in a format such as **DD-MMM-YYYY**. Check both the starting and ending dates.

## Read Student Absent Record

The table shows Date, Attendance Status, and Reason for the selected student's absent and late records. Check the whole date range and any table pagination before concluding that a record is missing.

This is a detail report, not a form for changing attendance. Correct the source in Admin-Daily Attendance or the appropriate subject session, then reload the report.

## Export the detail

After reviewing the student and range, use the available Print, Excel, or PDF action. Check the document title, identity, dates, and rows in the output before distributing it.

## Common problems

- **Table asks for a student:** select Student Name; filters alone do not identify one student.
- **Expected date missing:** check range, campus, grade, and the source attendance record.
- **Export disabled:** wait for the report to load and check permissions or validation messages.

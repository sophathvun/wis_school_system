## Before you start

Open **G12 National Exams → Result**. Printing or exporting result reports requires the separate result-export permission.

## Review results

1. Select **Academic Year**.
2. Narrow the list by campus, selected class, language, center, result, or student.
3. Check student identity, center, exam date, room, and seat.
4. Review Score / Rank, overall Letter Grade, and the result status.

The final result follows the overall Letter Grade: A–E are passed, F is failed, and a missing grade is pending. Check source grades in Scoring if a result is unexpected.

## Choose a result report

Use the available print or export controls and select the report you need:

| Report | Purpose |
| --- | --- |
| List of Grade A Students | Review candidates with overall grade A |
| List of Grade A Students By Campus | Review Grade A candidates grouped by campus |
| List of Result | Review candidate results in the report's school grouping |
| Passed/Failed Statistics to DoEYS | Prepare the DoEYS statistics output |
| Passed/Failed Statistics All | Review the available overall statistics output |

Check the current filters and preview before printing or distributing an export. A report's ordering may differ from the list currently shown on screen.

## Correct a result

Correct the authorized source record through Scoring or the reviewed import workflow, then reopen Result. Editing a downloaded file does not correct the system's data.

If you cannot see a student, clear restrictive filters and check the academic year and permitted campuses. If export controls are missing, ask your administrator to check result-export permission.

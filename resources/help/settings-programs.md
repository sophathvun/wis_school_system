## Open Programs

Go to **Settings → Programs**. Configure the required education level first.

## Create or update a program

1. Search the program list for an existing entry.
2. Open the new-record or edit form.
3. Select the **Education Level**.
4. Select an **Academic Year** when the program is specific to that year. Leave it blank only when the program should be configured without a year restriction.
5. Enter **Program Name** and **Program Code**.
6. Add a description if needed, select the status, and save.

The system checks duplicate program names and codes within the same education-level and academic-year combination. Review that combination if a duplicate message appears.

## Verify the result

Check the saved education level, year, code, and active status. Correct the existing program when fixing a spelling mistake instead of creating another program with the same meaning.

A program setting describes an academic offering. It does not create enrollments or assign students automatically.

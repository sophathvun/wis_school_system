## Choose a Settings page

Open **Settings** in the main menu. These pages maintain shared choices used by enrollment, family records, addresses, and reports. Menu visibility follows your permissions; viewing a page does not automatically allow creating, editing, deleting, or exporting its records.

| Page | Use it for |
| --- | --- |
| Academic Years | Regular academic years, Summer periods, year codes, and lifecycle statuses |
| Grades | Grade names, short names, and display order |
| Classes | Class names or letters and their display order |
| Sessions | Study-session names and abbreviations |
| Education Levels | Names and ordering of education levels |
| Programs | Programs belonging to education levels |
| School Information | School and campus names, addresses, contacts, and logos |
| Locations | Countries, provinces, districts, communes, and villages |
| Occupations | Occupation choices used by family records |
| Academic Tracks | Science stream and language combinations |
| Withdrawal Reasons | Choices available on withdrawal forms |
| Document Types | Categories available when uploading student documents |

## Prepare the shared choices

Create the required locations and school information, then academic periods, grades, classes, and sessions before preparing student placements. Configure education levels before their programs. Set up tracks, occupations, withdrawal reasons, and document types before staff need those choices.

## Maintain existing records

Search before adding a new record. Edit an existing entry to correct spelling instead of creating a second choice with the same meaning. Review records already using a name or code before changing it. Use the available inactive option when retiring a choice that must remain in historical records.

## Find instructions

Choose **Settings → Help & guides**, or select **Settings** in Help Center. Search by a page name or task, such as **Summer**, **Academic Tracks**, or **Document Types**. Each guide offers an **Open page** link when you have access.

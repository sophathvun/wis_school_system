## Open Locations

Go to **Settings → Locations**. Location choices support structured addresses and birthplaces for students, families, and school records.

## Follow the address hierarchy

Use the hierarchy **Country → Province → District → Commune → Village**. Create or select a parent location before maintaining its children.

1. Select the required location level and parent filters.
2. Search for the existing place, checking both English and Khmer names.
3. Open the new-record or edit form.
4. Enter the English name and the Khmer name when available.
5. For a child location, select the correct parent. Choose its status and save.

Country records also offer country codes, international phone codes, nationality names, and a flag image. A flag accepts JPG, JPEG, PNG, or WebP up to **2 MB**.

## Correct address choices

When a district, commune, or village is missing, first check the parent filters and active status. Avoid creating a duplicate under a different parent just to make it appear in a selector.

Changing the location catalog does not automatically identify or complete missing parts of a student's free-text address. Review those student records separately.

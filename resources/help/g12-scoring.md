## Before you start

Open **G12 National Exams → Scoring**. Entering or updating grades requires scoring management permission for the student's campus.

## Select the correct examination context

1. Select **Academic Year** and **Campus**.
2. Check **Selected Class**, **Language Exam**, and **Exam Center**.
3. Find the student and verify the room and seat.
4. Review which subjects the system displays for that exam language and selected class.

Only the subjects assigned to the current examination context can be saved. If the exam language or selected class changes, refresh before entering grades.

## Enter grades

Enter subject grades as **A, B, C, D, E, or F**. These fields do not accept G9 numeric subject scores. Review the official source rather than guessing a grade from an incomplete image or spreadsheet.

Record **Score / Rank** and the overall **Letter Grade** in their own fields. Score / Rank accepts a nonnegative numeric value with up to three decimal places; it is not a subject letter grade.

Save and check the resulting values. The overall Letter Grade controls the displayed final outcome: A–E are passed, F is failed, and an empty overall grade remains pending. Do not assume an entered set of subject grades automatically determines the official overall Letter Grade.

## Alternative entry methods

Use the scoring CSV workflow to preview spreadsheet updates. Use **Scan MoEYS Result Images** for OCR when configured and permitted. Both workflows require review before confirmation.

## Avoid overwriting newer work

If the system reports that scores changed in another window, refresh and reopen the student. Compare the latest values with the source before saving. Do not keep retrying an old form.

## Before you start

Open **Attendance → Attendance Reports → Attendance Statistics**. Viewing this tab requires statistics permission; exporting requires the relevant Print, Excel, or PDF permission.

## Set the report scope

1. Select Academic Year.
2. Choose Campus, Grade, and Student Name where required by your analysis.
3. Select the Date Range.
4. Review the table's headings, totals, and any summary information.

Keep the same scope when comparing two reports. A class view, a single student, and an all-campus view do not have the same denominator.

## Interpret daily attendance

Daily attendance represents attendance days. E and U are excused and unexcused absence respectively; missed periods provide context and do not multiply one day into several absence days. Tardy (T) is a separate status.

School weekdays and public holidays come from Attendance Settings for the selected year and campus. Review that calendar if expected working days or date coverage looks wrong.

Do not assume that blank attendance is automatically Present. Check the source register and the labels used by the current statistics table before interpreting an incomplete date range.

## Verify unexpected figures

Compare the selected student's detail report with the same date range, then inspect the source daily register. If a correction is needed, make it in the authorized source workspace and reload the statistics.

## Print or export

Use the export actions offered by the statistics tab. Review the preview and selected scope before sharing. Attendance reports contain student information and should be distributed only to the intended recipients.

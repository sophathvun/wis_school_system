## Open Sessions

Go to **Settings → Sessions**. Sessions describe when a student studies and are selected separately from grade and class.

## Add or edit a session

1. Find the existing session before adding another one.
2. Enter **Session Name** and **Session Short Name**; each must be unique.
3. Set **Session Order** and an optional description.
4. Choose the status and save.

Keep names aligned with the school's established choices, such as Morning, Afternoon, and Full-Day. Attendance study-group matching recognizes the short codes **M**, **A**, and **III**. Review attendance-period configuration before changing a short code used by existing placements.

## Verify the result

Check the label and order in the session list and student enrollment form. A missing choice may be inactive or unavailable in the selected context.

Changing the session catalog does not create a teaching timetable or move a student's enrollment to a different study session. Use the relevant enrollment and scheduling workflows for those changes.

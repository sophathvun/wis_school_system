## Before you start

Open **G12 National Exams → Scoring → Scan MoEYS Result Images**. OCR upload, review/confirmation, and OCR settings are separate permissions.

Google Cloud Vision OCR must be configured by an authorized administrator. The screen shows OCR availability or usage information. OCR uses an external service; do not assume that it is free or available simply because the upload form is visible.

## Upload one center's images

1. Select **Academic Year**, **Exam Center**, **Exam Language**, and **Selected Class**.
2. Enter **Room** if appropriate.
3. Choose readable MoEYS result images for that center.
4. Choose **Upload & Scan** and watch the progress and any failure messages.

Use one exam center per batch. Follow the form's current file-type, image-count, and file-size limits.

## Review every row

Check seat, matched student, subject grades, Score / Rank, overall Letter Grade, and status against the original image.

OCR can misread names, digits, or grades. A plausible match is not proof that the correct student was selected. Resolve unmatched or ambiguous rows using the available matching controls. Unmatched rows are skipped until a student is selected.

## Confirm reviewed scores

Users with OCR review permission can choose **Confirm Scanned Scores** after reviewing the batch. Inspect any rejected rows, then verify saved values in Scoring and Result.

Uploading or scanning images is not the same as confirming score changes. Do not use unreviewed OCR results to issue certificates.

## Troubleshooting

If OCR is unavailable, ask the administrator to check service configuration and usage limits. If a source image is unclear, obtain a clearer copy rather than guessing a grade.

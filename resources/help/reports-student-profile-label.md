## Prepare student file labels

1. Open **Reports > Academic Reports > Stu. Profile Label**.
2. Select the academic year, campus, and intended grade/class using the available filters.
3. Apply the filters and verify each student's identity and placement in the preview.
4. Check the print scope and format options offered for the report.
5. Use Print, Excel, or PDF as needed.

## Check a sample before printing a batch

Print one sample on plain paper first. Confirm paper size, scaling, alignment, and label content against the stationery you will use. Correct names or placement in student information or enrollment before reprinting.

If a student is missing, confirm the selected academic period and campus match the student's enrollment.

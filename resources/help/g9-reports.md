## Open a report

1. Open **G9 National Exams → Exam Result**.
2. Select the academic year and filters.
3. Choose **Print**, **Excel**, or **PDF**.
4. Select the required report.
5. Review the title, year context, exam center, dates, totals, and page breaks before using the document.

Exports include all matching candidates, not just the current table page. Statistics reports require statistics access.

## Understand absence in reports

- The individual result list displays **ធ្លាក់** in an absent student's Result column and keeps the absence reason separately.
- Room and WIS reports count absent candidates in their failed grade group. Their grade percentages use total registered candidates.
- DoEYS-style reports include absent students in registered totals and show absences separately. Passing grade and pass percentages compare with candidates who attended.
- Subject statistics count only present candidates with eligible entered scores. Subject pass marks use half the subject maximum.

These reporting rules do not change the student's attendance record or certificate eligibility.

## Dates and signatures

Set dates in **G9 Setting → Document Dates** for the correct year and center. The individual result list uses Result Issue Date above the center signature and DoEYS Result Issue Date in its approval block.

DoEYS-style school signatures use the Khmer lunar and solar **Result Issue Date**. Phnom Penh uses **ជ.នាយកសាលា / នាយករង**; provincial settings use **នាយកសាលា**. WIS uses the same Result Issue Date in its **ការិយាល័យសិក្សា** card, displayed as **August 12, 2026**.

## Print troubleshooting

Allow the report popup if your browser blocks it. Select A4 and the report's intended orientation. Check browser headers and footers if extra text appears on the page.

Current Print Preview uses a normal report URL and can be refreshed. Older tabs whose addresses start with **blob:** may have expired; close them and reopen Print from the results screen.

Table header colors are configured to print. If your printer still omits them, check the browser's background graphics and printer color settings.

## Before you start

Open **G9 National Exams → G9 Imports/Export**. Importing and exporting require their own permissions. Confirm the academic year and campus context.

## Prepare a workbook

1. Download the current import template from the page.
2. Keep the template's expected column structure.
3. Enter student IDs consistently and verify Khmer and English names.
4. Check year, campus, exam center, exam language, room, seat, and date values.
5. Keep an unchanged copy of the original source workbook.

Do not assume that an old-system backup uses the current template. Historical certificate backups need separate matching and review; the candidate import page is not a substitute for the reviewed certificate-backup process.

## Preview before confirming

Upload the prepared workbook and run the preview. Read validation messages and review matches, proposed changes, and any rejected rows. Correct the source or matching issue before confirming.

Confirm only when the preview reflects the intended records. A successful upload alone does not mean the import has been committed.

## Check the result

Open import history when available and verify the affected students in List of Candidate. Recheck filters if records do not appear. Review errors instead of repeatedly importing the same workbook without inspecting the result.

## Export

Use the available export action for the required year and scope. Review the exported data before distributing it; workbooks may contain student information.

## Before you start

Open **Attendance → Admin-Daily Attendance**. Recording new marks, editing existing or past records, and deleting records require separate permissions.

## Select the daily register

1. Select the academic year.
2. Select the campus and **Grade** or class.
3. Choose the date using the date navigation, previous/next controls, or **Today**.
4. Use Student Name or Search to find a student when needed.
5. Check the roster and displayed date before making changes.

Daily attendance cannot be saved for a future date. Use the approved-leave workflow for an authorized future absence.

## Choose the daily status

| Display | Meaning |
| --- | --- |
| P | Present |
| E | Excused absence |
| U | Unexcused absence |
| T | Tardy |

E and U each count as one absence day. Missing one, two, or more subject periods still represents one daily attendance day. The selected absent periods or session count provide context rather than multiplying the daily total.

Select E, U, or T to choose absent periods and enter a reason using the available controls.

## Apply Present to blank records

Use **P — Apply to Blank** only after reviewing the class and date. It applies Present to blank attendance and does not overwrite existing marked records. Do not use it to replace an absent student's existing status.

## Check automatic saving

Changes save automatically. Watch the save message and any validation error. If saving fails, resolve the problem and use **Retry Save** when offered before leaving the page.

## Correct a past date

Past attendance is read-only until an authorized user chooses **Edit**. Check the date, make the intended correction, and verify that it saved. Attendance history is retained; deleting a mark does not erase the audit trail.

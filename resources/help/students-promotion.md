## Before you start

Open **Students → Student Promotion**. Review the source enrollments and the configured destination year, grade, class, and session before applying any promotion.

Promotion is an academic progression workflow. It is different from a campus/class transfer or an exceptional Grade Skipping approval.

## Prepare a promotion

1. Choose **New Promotion**.
2. Select the source scope and intended students using the form's available choices.
3. Verify source academic year, campus, grade, and class.
4. Select the destination academic year and placement offered by the form.
5. Review all selected students and any effective-date or other required fields.
6. Confirm using the available workflow action.

Destination choices depend on academic-year lifecycle and class configuration. Do not select a different year simply to bypass an unavailable destination.

## Verify the outcome

Review **Promotion History**, the affected students, and their destination enrollment information. Confirm that the change was saved before repeating an operation.

One student can have records in several academic years. Keep the same student identity rather than creating a new Student ID for each promotion.

## Corrections and history

Use the available history and correction, cancellation, or reversal actions when permitted. Check both source and destination records before reversing a completed operation; subsequent academic changes may affect what can be reversed.

## Troubleshooting

If a student or destination is unavailable, inspect active enrollment, year lifecycle, campus, and class configuration. Read the workflow's validation message before preparing another batch.

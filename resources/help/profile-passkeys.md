## Open passkey settings

Go to **My Profile → Edit Profile** and find **Face or Passkey Login**. This section manages sign-in credentials for your own account.

## Register a device

1. Enter a recognizable **Device name**, such as Office Laptop.
2. Enter your **Current password** in the passkey section.
3. Select **Add Face or Passkey**.
4. Complete the verification offered by your browser or device, such as Windows Hello, Face ID, a fingerprint, a device PIN, or a security key.
5. Check the success message and the updated passkey list.

Registering a passkey uses its own action; it does not require saving the unrelated profile fields. Save any separate profile edits with **Save changes**.

## Review or remove a passkey

The list shows each device name, the date added, and its last use when available. Use the remove button beside the correct entry and review the confirmation. Removing that credential prevents it from being used for future sign-in to this account.

## Resolve a problem

The browser must support passkeys and a secure connection. If the page says the feature is unavailable, ask your administrator to check the connection and browser support. If the request expires or device verification is cancelled, start the registration again.

Use the normal permitted sign-in method when a passkey is unavailable. Never enter another staff member's password or register a shared credential for their account.

## Open Document Types

Go to **Settings → Document Types**. This page controls the categories available for student document uploads.

## Create or edit a type

1. Search the existing types to avoid duplicate categories.
2. Open the new-record or edit form.
3. Enter a unique **Type Key** using letters, numbers, dashes, or underscores.
4. Enter the English label and the Khmer label when available.
5. Set **Sort Order**, choose the status, and save.

Use clear labels that help staff select the correct category, such as Birth Certificate or Transcript. Keep a type key stable once documents use it.

## Verify upload choices

Open **Students → Student Documents** and check that the intended category is available for the student's upload. Document Types configures categories; it does not upload a file or change the file-size and format requirements of the document uploader.

## Retire a type

The delete action deactivates the type. It does not delete the student's existing document files. Use the document-management page when reviewing or correcting an individual uploaded document.

## Before you start

Open **Students → Stu. ID Card (QR)**. Viewing, generating QR codes, printing individual cards, printing a whole class, copying links, and editing templates have separate permissions.

## Select the student or class

Use the available year, campus, grade/class, student, and **Print Scope** filters. Verify Student ID, name, photo, and class details before generating or printing a card.

## Generate a QR code

Use **Generate QR** for the intended selection when permitted. Check the resulting link or QR preview and ensure it belongs to the correct student.

A QR/public card link is different from access to the full school system. Share it only for its intended school use and do not assume it grants access to private profiles or documents.

## Print cards

Choose the individual or whole-class print scope and use the available print action. Review names, photos, QR codes, and card boundaries in the preview before printing the batch.

If a copied link is needed, use the provided Copy Link action rather than constructing a URL from a student's name or ID.

## Edit the template

Template editing requires its own permission and applies across academic years. Use the editor's Save, Discard, or Restore actions deliberately and preview representative cards before saving a shared design change.

## Troubleshooting

If printing is unavailable, check both the selected scope and its corresponding print permission. If a photo or name is wrong, correct the source student information and reopen the card rather than editing only a printed copy.

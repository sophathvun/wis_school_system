## Before you start

Open **G12 National Exams → Student Exam Records**. Creating and editing require separate permissions and are limited to permitted campuses.

## Find an exam record

1. Select **Academic Year**.
2. Narrow the list with **Exam Language**, **Selected Class**, **Campus**, or **Grade**.
3. Search by student ID or name.
4. Verify the student ID and Khmer name before opening the record.

## Create or edit a record

Use the available add or edit action. Fill in the fields offered by the form, check the student, year, campus, and examination context, then choose **Save Record**.

Student ID and academic year are fixed after creation. If either is wrong, ask an authorized administrator to review the record rather than changing a different student's details to make it fit.

National exam information is kept separately from the school student profile. Editing an exam name or detail should not be treated as a general correction to the student's school profile.

## Check related information

Use **Assign Exam Center** for center, room, and seat assignments. Use **Scoring** for subject grades and overall Letter Grade. Use **Certificate Tracking** for certificate documents and collection.

## Common problems

- **Student missing:** check year, campus access, selected class, and search filters.
- **Add or edit unavailable:** check the record creation or editing permission.
- **Record changed elsewhere:** refresh, reopen the student, and review the latest values before saving again.

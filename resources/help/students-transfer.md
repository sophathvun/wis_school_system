## Before you start

Open **Students → Student Transfer**. Review the source student enrollment and intended destination before starting. Available actions depend on permissions and the workflow's current eligibility checks.

Use Transfer for the supported campus or class changes. Use Promotion for normal academic progression and Re-entry for a student returning after official withdrawal.

## Prepare a transfer

1. Choose **New Transfer**.
2. Select the source scope and intended student or students.
3. Verify current campus, class, year, and session.
4. Choose the destination campus/class and other required placement fields.
5. Review the effective date and every selected student.
6. Confirm using the available action.

Check both **Transfer From** and **Transfer To**. A similarly named class in another campus is not necessarily the intended destination.

## Verify the transfer

Review **Transfer History** and open the affected student's enrollment information. Check that the new placement is correct and that the old and new information remain understandable in history.

## Correct an error

Use the available workflow correction or reversal controls where permitted. Check for later changes before reversing a transfer. Do not create another student identity to repair a placement mistake.

## Troubleshooting

If the student already has an active destination enrollment, inspect the conflict before retrying. If destination options are missing, check year, campus, grade, class, and session setup and the permitted scope.
